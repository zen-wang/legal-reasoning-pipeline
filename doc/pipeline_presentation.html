Motivation

Why Not Just Use an LLM?

Black-Box LLM

  • Hallucinated citations — invents case names that don't exist
  • Opaque reasoning — no way to trace why it reached a conclusion
  • Unfaithful CoT — reasoning traces can "fabricate justifications that contradict the true reasoning paths"
  • Unfixable — if wrong, retrain the whole model?

Neuro-Symbolic Pipeline

  • Verified citations — every case checked against real dataset
  • Traceable reasoning — element → fact → statute → precedent
  • Editable rules — if wrong, fix the symbolic rule directly
  • No retraining — edit a rule, re-run, see the fix

"Life demands safe, accurate, and hallucination-free programmable AI, built from proven scientific hypothesis and governed by human oversight." — Beyond the Black Box (IEEE TCSS 2026)

03
Core Architecture

Lifting & Lowering

  • Lifting = translate LLM output into symbolic logic (structured patterns a human can read)
  • Lowering = inject symbolic constraints back into neural generation (the LLM can only reason about verified facts)
  • Symbolic Rule Interface sits in between — human-readable, human-editable boolean templates
  • Exception Handling = human reviews failures, fixes rules, re-runs — no full retraining

From Beyond the Black Box (Trivedi et al., IEEE TCSS 2026) Algorithm 1

03
The Loop
  • 1. Neural theme extraction
  • 2. Symbolic pattern lifting
  • 3. Store as rule interface R
  • 4. Pattern lowering (constrain LLM)
  • 5. Exception handling (human review)
  • 6. Modify rules → back to step 4

"Programmable" = you can fix the AI by editing the rules

04
Legal Domain

Rule 10b-5: The 6-Element Test

Federal anti-fraud rule for securities. Investor sues company. All 6 elements must be satisfied — any single failure means defendant wins.

PlaintiffWins(case) ← MaterialMisrep(case) AND Scienter(case) AND Connection(case) AND Reliance(case) AND EconomicLoss(case) AND LossCausation(case) /* Sub-rules (disjunctive — any one can satisfy the element): */ Scienter ← MotiveAndOpportunity OR ConsciousMisbehavior OR RecklessDisregard Reliance ← FraudOnTheMarket OR DirectReliance OR AffiliateOmission LossCausation ← CorrectiveDisclosurePriceDrop OR MaterializationOfConcealedRisk

This conjunctive structure makes 10b-5 perfect for symbolic reasoning — the rule is precise enough to encode, but reasoning within each element requires LLM-level comprehension.

These 6 elements × 14 sub-conditions are encoded in rules.py as the symbolic backbone. The LLM extracts which are satisfied; the rules evaluate the outcome.

Phase 1

Symbolic Lifting: Text → Structured IRAC

The LLM reads each opinion and extracts a machine-readable IRAC analysis per the 6-element schema.

class ElementAnalysis(BaseModel): status: ElementStatus # SATISFIED | NOT_SATISFIED | CONTESTED | NOT_ANALYZED sub_conditions: list[str] # e.g. ["FraudOnTheMarket"] — validated against ELEMENT_RULES key_facts: list[str] # supporting facts from the opinion judge_reasoning: str # relevant quote from the judge confidence: float = 0.0 # computed post-hoc, NOT filled by LLM
  • Pydantic v2 validation — schema enforced on every LLM output
  • Sub-condition validation — "FraudOnTheMarket" valid for reliance, not for scienter
  • Anti-hallucination — case_id, opinion_id, procedural_stage injected post-hoc, never by LLM

Phase 1

Sample: Minneapolis Firefighters v. MEMC

Raw Opinion (50K chars)

"...The district court concluded the pre-class period disclosures could not create a duty on MEMC's part to disclose the incidents... We do not believe the inference of scienter is as compelling as the more innocent, simpler inference..."

Structured Output (JSON)

The LLM correctly identified both elements as NOT_SATISFIED and extracted the judge's reasoning. This is structured extraction, not summarization.

Phase 5

6 Hard Constraints ("Practical Wisdom")

From Hybrids (Newson et al.) — structural requirements that no prompt engineering can guarantee.

#ConstraintSeverityWhat It Catches
1Citation checkERRORHallucinated case names not in our dataset
2Statute groundingWARNINGStatutes outside the known 10b-5 vocabulary
3Binding authorityWARNINGCross-circuit citations (persuasive, not binding)
4Temporal validityERRORCiting a case filed after the query case
5Ambiguity flagINFOANCO-HITS score near zero → genuinely contested
6Missing elementWARNINGNOT_ANALYZED elements must be explicitly stated

109 federal courts mapped to 13 circuits + SCOTUS. Constraints enforced both in prompt AND as post-generation validators.

Phase 5

Graceful Degradation

When the LLM is offline, the pipeline still works. The symbolic layer is self-sufficient.

  • SymbolicOnlyResult contains: IRAC extraction + ANCO-HITS score + ranked precedents + constraint violations
  • No natural language IRAC, but all structured analysis still works
  • Reinforces the Beyond the Black Box thesis: symbolic pipeline is independent of LLM
21
Two Paths
  • LLM Online → IRACAnalysis (full natural language + constraints)
  • LLM Offline → SymbolicOnlyResult (structured analysis only)

Both paths go through constraint validation. The user always gets verified analysis.
