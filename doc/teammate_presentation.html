Motivation

Why Not Just Use an LLM?

Black-Box LLM

  • Hallucinated citations — invents case names that don't exist
  • Opaque reasoning — no way to trace why it reached a conclusion
  • Unfaithful CoT — reasoning traces can "fabricate justifications that contradict the true reasoning paths"
  • Unfixable — if wrong, retrain the whole model?

Programmable AI

  • Traceable — element → fact → statute → precedent chain
  • Editable — fix the symbolic rule directly, no retraining
  • Verifiable — every citation checked against a real dataset
  • Zero hallucination — post-generation constraint validation catches fabrications

"Life demands safe, accurate, and hallucination-free programmable AI, built from proven scientific hypothesis and governed by human oversight." — Beyond the Black Box (IEEE TCSS 2026)

Core Concept

What is Neuro-Symbolic?

Neural (Learns Patterns)

  • LLMs, embeddings, deep learning
  • Strength: can read and interpret 50K-char opinions
  • Weakness: opaque, hallucinations, unfixable
  • Alone: ~60-75% accuracy, unverifiable

Symbolic (Explicit Rules)

  • Boolean logic, knowledge graphs, constraint validation
  • Strength: traceable, editable, provably correct
  • Weakness: brittle, can't read natural language
  • Alone: ~55-65% accuracy, can't handle nuance

Neural reads the text. Symbolic enforces the rules. Together they are greater than either alone.

Why Private 10b-5?

Private litigation is more interesting than SEC enforcement for neuro-symbolic reasoning:

Outcome varietyPLT / DEF / MIXED76% consent judgments

Data Architecture

273 Unlabeled Cases

Cases with no opinion text — metadata-only records from CourtListener.

Where They Help

  • Graph bridges — connect opinion-bearing cases through shared citations
  • Intermediate hops — 2-hop traversal in Neo4j passes through unlabeled nodes
  • Citation density — 13,530 citation edges come from all 416 cases
  • Metadata features — court, date, parties, attorneys still available

Where They Don't Help

  • No lifting — can't extract IRAC without opinion text
  • No ANCO-HITS — need arguments from IRAC to build bipartite graph
  • No embedding — can't encode a non-existent opinion
  • No eval — can't evaluate accuracy without ground truth

Graph infrastructure, not analysis targets. They make the citation network richer but are not directly analyzed by the pipeline.

Phase 3

ANCO-HITS Argument Scoring

From NARRA-SCALE (Gokalp et al., ICTAI). Score every argument and case on [-1, +1].

/* Per-entity normalization (Paper Eq. 1) */ xi(k) = Σj(aij · yj(k-1)) / Σj|aij · yj(k-1)| // case score yj(k) = Σi(aij · xi(k)) / Σi|aij · xi(k)| // argument score

Worked Example: 3 Cases, 4 Arguments

  • Case 1 (PLT_WINS): Arg A (+1), Arg B (+1)
  • Case 2 (DEF_WINS): Arg A (-1), Arg C (+1)
  • Case 3 (MIXED): Arg D (0)
  • After iteration: Arg A contested (appears in opposing outcomes), Arg B pure plaintiff, Arg C pure defendant

Phase 3

The Singleton Problem

353 of 370 arguments are singletons — connected to exactly 1 case. Per-entity normalization on a singleton: raw / |raw| = ±1 always.

ApproachWhat It DoesSingletons?
NARRA-SCALEGraph propagation on signed bipartite edgesAll extremal (±1)
Black Box LLMDirect prediction from textNo singletons
SBERT DedupMerge semantically similar argumentsReduces singletons

Why Scores Are Extremal (and That's OK)

  • 17 shared arguments all have uniform signs — no conflicting signals yet
  • At 3,400 cases, many arguments will be shared across cases
  • AUC = 0.687 against regex labels is honest (not circular)

Plan: SBERT semantic deduplication first → assess reduction ratio → codebook/clustering later if needed.

Results

Graceful Degradation

Only LLM generation fails — everything else works. This is the thesis proof.

With LLM (IRACAnalysis)

  • Natural language IRAC synthesis
  • Element-by-element assessment with reasoning
  • Precedent citations grounded in real cases
  • Constraint validation on generated text
  • Full structured output: Issue, Rule, Application, Conclusion

Without LLM (SymbolicOnlyResult)

  • Phase 1 IRAC extraction from prior run
  • ANCO-HITS case score from Phase 3
  • Ranked precedents from hybrid retrieval
  • Constraint violations from post-validation
  • No natural language, but all structured analysis works

Both paths go through constraint validation. The user always gets verified analysis.

Phase 7

Evaluation Framework

7 Anti-Pattern Rules

  • No test-set tuning
  • No self-evaluation (pipeline output cannot be its own ground truth)
  • No single-metric reporting (always: primary + per-class + 95% CI + N)
  • No data leakage
  • Component vs end-to-end separation
  • Zero-shot vs few-shot reported separately
  • Constraint violations as first-class metric
